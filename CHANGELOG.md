# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project uses semantic versioning for release tags.

## [v0.1.0] - 2026-05-06

### Added

- Official-source-first company research workspace with research brief, financials, charts, models, peers, and related company surfaces.
- Watchlist workspace for local-first research triage and follow-up.
- Data Sources workspace with source registry and cache transparency views.
- Dockerized backend, worker, and frontend runtime with publishable backend/frontend images.
- Release verification and compatibility checks for backend/frontend route contracts.

### Changed

- Release process standardized with a maintainer checklist and smoke-release script.

### Notes

- This is the first public baseline release for repeatable deploys and tagged image publishing.
